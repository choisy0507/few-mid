# The Language of Scent

An interactive visual guide to fragrance families, notes, and sensory descriptions, developed for the Front-End Web midterm.

## Overview

The site introduces three different kinds of fragrance information—family, note, and descriptor—then lets visitors explore how terms connect. Its eight-family atlas uses selected examples, including notes that appear in more than one family. The Powdery / Soapy comparison illustrates how similar-sounding descriptions can refer to different impressions.

## Files

- `index.html`: structure and content of the page
- `style.css`: typography, visual design, layout, and responsive styles
- `data.js`: selected fragrance terms and their relationships
- `main.js`: family selection, detail views, and comparison interactions

## Run locally

Open `index.html` in a browser, or use the VS Code Live Server extension. No build step is required.

## Notes on the content

The eight fragrance families are based on [The Perfume Society's introduction to fragrance families](https://perfumesociety.org/discover-perfume/an-introduction/fragrance-families/). Examples and connections are intended to support exploration; they are not quantitative scent measurements or a comprehensive reference.
