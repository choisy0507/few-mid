Front-End Web · Week 06 Midterm Design Presentation

프로젝트를 설명하는 글

저는 향수를 설명하는 언어가 어렵다는 문제에서 이 프로젝트를 시작했습니다. ‘우디’, ‘파우더리’, ‘머스키’라는 말을 읽어도 실제로 어떤 느낌을 가리키는지, 비슷한 표현 사이에서 무엇을 구별해야 하는지 알기 어렵습니다. ‘Woody는 나무 향’이라는 짧은 정의를 알아도 마른 나무의 결과 둥글고 매끈한 목질감의 차이는 여전히 남습니다. 이 프로젝트는 바로 그 차이를 이해하는 데 초점을 맞춥니다.

향에 대한 정보가 없어서만 생기는 문제는 아닙니다. 향수 설명에는 구체적인 대상을 가리키는 노트, 향의 큰 방향을 묶는 계열, 질감과 인상을 설명하는 표현이 함께 등장합니다. Rose는 노트, Floral은 계열, Creamy는 감각 표현입니다. 서로 연결되지만 동일한 종류의 정보는 아닙니다. 이것들을 같은 수준의 카테고리로 나열하면 단어는 많아져도 이해는 충분히 깊어지지 않습니다.

그래서 저는 하나의 향 설명을 여러 관점으로 읽는 웹 경험을 제안합니다. 사용자는 꽃잎과 나무의 결을 연상시키는 하나의 시각적 장면에서 출발합니다. Notes 관점에서는 구체적인 향의 대상이 드러나고, Feel 관점에서는 질감과 인상이 부각되며, Family 관점에서는 큰 방향을 묶어 볼 수 있습니다. 장면은 유지되지만 관점에 따라 읽는 정보와 강조의 단위가 달라집니다. 세 종류의 정보를 설명문으로만 배우는 대신, 사용자가 직접 관점을 바꾸면서 차이를 경험하도록 설계했습니다.

대표 사례는 Rose + Cedarwood와 Rose + Sandalwood입니다. 장미의 대상은 유지하고 나무 노트의 두 대표적인 묘사를 비교합니다. 전환할 때 장미의 형태와 위치는 그대로 남으며, 나무와 연결된 질감과 설명이 달라집니다. 여기서 강조하는 것은 무엇이 유지되었고 무엇이 달라졌는지, 그리고 다음 시향에서 무엇에 주목하면 좋을지입니다. 단어를 선택했을 때 정의만 나타나는 것보다, 자신의 선택을 통해 차이가 읽히는 경험을 만들고 싶습니다.

시각적 임팩트도 이 이해의 변화에서 만들고 싶습니다. 처음에는 겹쳐 보이는 추상적인 장면이지만, 선택하면 일부가 강조되고 다른 부분이 물러나면서 역할과 관계가 드러납니다. 질감과 색은 장식이 아니라 관심의 방향을 안내합니다. 파우더의 고운 입자, 마른 목재의 가는 결, 매끈하게 이어지는 곡선은 감각을 생각해 볼 단서가 됩니다. 다만 이러한 이미지가 실제 냄새를 정확하게 재현한다고 전제하지는 않습니다.

기존 향수 탐색에서 활용되는 향 계열, 노트, 비교, 지도라는 형식을 사용하면서도, 이 프로젝트의 진입점은 제품이나 전체 분류표가 아니라 하나의 이해하기 어려운 설명입니다. 지도와 비교 기능이 존재한다는 사실만으로 차별화를 주장하지 않습니다. 차별화하고 싶은 부분은 개념을 이해하는 순서와, 사용자 행동에 따라 정보의 관계가 읽히는 방식입니다. 사례를 이해한 뒤에는 관계 지도를 통해 더 넓은 향의 언어로 이동할 수 있습니다.

이 경험은 향수를 만드는 조합 게임보다 조용한 관찰실이나 인터랙티브 에디토리얼에 가깝습니다. 사용자는 정답을 맞히거나 향수를 완성해야 하는 대신, 궁금한 부분부터 자유롭게 살펴보고 관점을 왕복합니다. 첫 버전은 한 장면, 세 관점, 두 사례에 집중합니다. 목표는 향을 실제로 맡은 것처럼 알게 하는 것이 아니라, 향수 설명을 읽고 다음 시향에서 어떤 차이를 관찰할지 더 구체적으로 말할 수 있게 하는 것입니다.

1. Concept / Premise

하나의 향 설명을 세 관점으로 읽고, 작은 차이를 직접 확인하는 인터랙티브 웹 경험.

주제: 향을 설명하는 언어와 정보 사이의 관계.

대상: 향수 용어가 익숙하지 않거나, 단어의 뜻을 알아도 조합의 의미를 이해하기 어려운 방문자.

중심 질문: “같은 장미, 다른 나무. 어떤 차이에 주목하면 될까요?”

중심 행동: Notes / Feel / Family 관점 전환, 요소 집중, 두 설명 사례 비교.

사용자에게 남길 것: 계열·노트·표현의 차이와 다음 시향에서 관찰할 단서.

노트는 반드시 실제 원료나 배합 비율과 일치하지 않습니다. 계열은 분류 체계에 따라 달라질 수 있습니다. 감각 표현은 여러 노트와 계열에 겹쳐 쓰일 수 있습니다. 대표 사례는 미리 작성한 교육용 설명이며 실제 조향 결과를 계산하지 않습니다.

2. Intended Experience

항목의도한 경험이를 만드는 설계
Feel차분함, 호기심, 탐색의 여유종이색 바탕, 소재 질감, 자유로운 관점 전환
Notice대상·질감·큰 방향은 다른 정보같은 장면의 라벨과 강조 단위가 관점별로 바뀜
Discover같은 방향 안에도 서로 다른 인상이 존재동일한 장미를 유지하는 두 나무 노트 사례 비교
Understand관계가 있어도 동의어는 아니라는 사실유형 기호와 이름, 관계 설명, 관찰 질문
Do선택·집중·전환·비교·연결클릭, 터치, 키보드로 동등하게 접근

Before: “Woody는 그냥 나무 향 아닌가?”

After: “같은 우디 방향에서도 마른 결과 매끈한 질감을 따로 관찰해볼 수 있겠다.”

학습 효과는 아직 검증하지 않았습니다. 발표 피드백과 짧은 사용자 테스트에서 이 변화가 일어나는지 확인합니다.

3. References / Inspiration

레퍼런스는 모양을 따라 그릴 대상보다, 경험의 설계 판단을 돕는 자료로 사용합니다.

원문 URL과 검토 상태는 REFERENCE-NOTES.md에 정리했습니다. 외부 사이트는 현재 환경에서 403 네트워크 제한으로 원문을 확인하지 못했습니다. 제품·분류·퀴즈 관련 분석은 사용자가 제공한 레퍼런스와 대화에 기반합니다. 모든 서비스에 해당 기능이 없다는 주장이나 시장 전체에서 유일하다는 주장은 하지 않습니다. 디자인 문헌과 편집 스타일은 설계 참고 대상으로 구분했습니다.

4. Mood / Vision Board

키워드: Quiet / Tactile / Curious / Layered.

디지털 향 관찰실의 분위기입니다. 고운 가루, 꽃잎의 얇은 결, 마른 나무 조각, 매끈한 표면, 직물, 겹친 반투명 종이를 한 보드로 구성했습니다. 서로 다른 소재를 대비시켜 대상과 질감을 관찰하는 시선을 만듭니다.

무드보드의 이미지는 이 프로젝트를 위해 생성한 시각적 비유입니다. 실제 원료의 사진 증거나 후각 측정 자료가 아닙니다. 향수병이나 브랜드 이미지를 중심에 놓지 않아도 향의 느낌을 탐색할 수 있는 방향을 제안합니다.

6. Sitemap

한 페이지 안에 다음 영역과 상태가 존재합니다.

HOME / STUDY
├─ 질문과 대표 장면
├─ PERSPECTIVE: Notes ↔ Feel ↔ Family
│  └─ 요소 집중 / 의미 / What to Notice
├─ COMPARE: Cedarwood ↔ Sandalwood 사례
│  └─ 유지된 것 / 바뀐 것 / 구별할 단서
├─ CONNECTIONS: 사례에서 관련 개념으로
└─ ABOUT / CONTENT BASIS
   └─ 정보 유형 / 표현의 한계 / 참고 자료

Notes·Feel·Family는 별개의 필수 페이지가 아니라 동일한 장면의 관점입니다. 비교와 관계 탐색은 왕복할 수 있고, 관점을 바꾸어도 선택한 사례가 유지됩니다.

7. User Flow

대표 흐름:

질문과 장면을 만남 → Notes에서 대상을 발견 → Feel에서 질감의 역할을 읽음 → 나무 노트 사례를 전환 → 공통점과 차이를 확인 → Family에서 큰 방향을 이해 → 관련 개념으로 연결.

다른 흐름도 허용합니다. 사용자는 Feel이나 Family부터 시작할 수 있고, 언제든 이전 관점으로 돌아올 수 있습니다. 선택은 학습 미션이나 정답 판정이 아니라 탐색입니다. “전체 장면 보기”는 집중 상태만 해제하고, 선택한 사례와 관점은 유지합니다.

8. Wireframes

중요한 화면과 상태를 별도의 시각 자료로 설계했습니다.

1. 첫 진입 / Notes: 질문, 세 관점, 겹친 장면, 요소 라벨, 설명 패널, 사례 전환.

2. Feel / Family 상태: 같은 장면에서 읽는 정보의 범위와 강조 단위가 달라짐.

3. 요소 집중: 선택한 부분은 유지하고 다른 요소를 약화해 관계와 역할을 읽기.

4. 두 사례 비교: 공통 부분은 고정하고 변경된 대상과 관찰 단서 강조.

5. 모바일: 장면·관점·설명·비교가 좁은 화면에서 읽기 순서로 재배치.

assets/의 와이어프레임 이미지와 발표 자료에 배치도, 상태, 중요한 요소의 역할을 표시했습니다. prototype/index.html에서는 실제 관점 전환과 집중·사례 비교를 시험할 수 있습니다.

9. Responsive Intentions

관계넓은 화면좁은 화면유지할 것
장면과 설명장면 왼쪽, 설명 오른쪽장면 아래 설명선택한 사례와 관심 대상
관점 전환상단 가로 배열세 버튼을 압축해 가로 유지세 질문의 의미와 선택 상태
비교공통점·변경점·단서 3열읽기 순서로 한 열무엇이 달라졌는지
연결노트–표현–계열의 가로 관계세로 관계와 설명정보 유형 이름과 관계의 이유
조작마우스와 키보드터치와 키보드hover 없이 접근 가능한 설명

디자인 프로토타입은 약 680px에서 장면과 설명을 쌓고, 중간 폭에서는 패널 폭과 여백을 먼저 줄입니다. 이 수치는 기기 목록의 정답이 아니라 현재 콘텐츠가 필요로 하는 시작점입니다. 실제 화면에서 조밀함과 읽기 길이를 보고 조정합니다.

관점은 키보드 방향키로도 전환하며 Enter/Space로 요소를 선택합니다. 선택 상태는 ARIA와 시각 표시를 함께 제공합니다. prefers-reduced-motion에서는 움직임 없이 최종 정보를 표시합니다.

구현 상태와 다음 작업

기존 v1 구현: 12개 개념의 관계 지도, 관련 개념 강조, 표현 비교, 텍스트 대안, 11개 브라우저 테스트 통과.

별도 제출용 디자인 프로토타입: Notes / Feel / Family 전환, 부분 집중, 두 나무 노트 사례 전환, 관계 확인. 기존 웹사이트의 첫 화면을 교체한 것은 아닙니다.

다음 개발: 발표 피드백을 반영해 대표 화면과 기존 관계 지도를 통합하고, 시각적 선택의 의미와 콘텐츠 근거를 검토합니다.

후속 범위: 시간에 따른 향의 전개. 현재 발표에서는 확장 가능성만 언급하며 완성 기능으로 소개하지 않습니다.
