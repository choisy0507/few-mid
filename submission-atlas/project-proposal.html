프로젝트를 설명하는 글

저는 향의 이름을 알고도 어떤 느낌인지, 다른 표현과 무엇이 다른지 이해하기 어렵다는 문제에서 이 프로젝트를 시작했습니다. 향수 설명에는 Floral, Rose, Powdery, Musk 같은 단어가 함께 등장하지만 이 단어들이 모두 같은 종류의 정보는 아닙니다. 계열은 큰 방향을, 노트는 떠오르는 냄새의 대상을, 감각 표현은 질감과 인상을 설명합니다. 단어를 많이 나열하거나 ‘Woody는 나무 향’이라고 정의하는 것만으로는 그 사이의 관계를 충분히 이해하기 어렵습니다.

제가 가장 강조하고 싶은 것은 향의 전체적인 구조와 그 안의 연결을 직관적으로 읽는 경험입니다. 사용자는 먼저 여덟 개의 주요 향 계열로 전체적인 방향을 파악합니다. 한 계열을 선택하면 원래 지도 안에서 관련 노트와 감각 표현이 펼쳐집니다. 선택하지 않은 다른 일곱 계열도 보조적으로 남아 있어, 세부 내용을 살펴보면서 전체 지도에서 현재 위치를 잃지 않습니다. 이것이 이번에 선택한 A 대안의 핵심입니다.

정보의 정확성을 위해 내부 데이터와 화면 구조를 다르게 설계했습니다. 내부적으로는 Family, Note, Descriptor, Accord, Material을 구분합니다. 다섯 유형은 하나의 트리에서 같은 깊이에 놓이는 카테고리가 아닙니다. Family·Note·Descriptor는 향을 설명하고 이해하는 관점에 가깝고, Accord·Material은 인상을 구성하고 구현하는 방법에 가깝습니다. 지도에서는 큰 방향·대상·감각을 중심으로 보여주고, 조합과 실제 향료는 사용자가 더 궁금해졌을 때 상세 설명에 녹여 보여줍니다.

겹치거나 모호한 단어는 한 항목 아래에 억지로 넣지 않고, 정보 유형과 특징을 분리했습니다. 예를 들어 Sandalwood의 유형은 Note입니다. 이 노트는 Woody와 연관되면서 Creamy, Warm, Dry 같은 면으로 묘사될 수 있습니다. 그렇다고 Sandalwood가 Creamy의 하위 분류인 것은 아닙니다. 또 Musk라는 노트와 Musky라는 표현을 별도로 두었습니다. 한 노트가 여러 계열과 연결되고, 하나의 표현도 여러 노트에서 나타날 수 있도록 관계망으로 구성했습니다.

화면의 시각 언어는 기존에 선호했던 편집 디자인을 유지했습니다. 종이색 바탕, 깊은 초록색 글자, 세리프 제목, 연두색 선택 강조, 가는 연결선, 우측 설명 패널이 중심입니다. 선택하면 관련 개념은 또렷해지고 다른 정보는 물러납니다. 질감 이미지와 생활 속 장면은 추상적인 설명을 생각해 볼 단서로 사용합니다. 이미지가 실제 냄새를 정확히 재현하거나 색상과 거리가 객관적인 유사도를 나타낸다고 주장하지 않습니다.

향 비교는 전체 지도와 동등한 주요 입구보다, 개념을 살펴보다 더 궁금해질 때 여는 심화 경험으로 배치했습니다. 예를 들어 Floral에서 Musk 노트를 발견한 뒤 그 상세 설명 안에서 깨끗한 머스크와 따뜻한 머스크의 두 맥락을 비교할 수 있습니다. 기존 비교 화면의 두 인상 카드와 오각형의 분위기는 유지하되, 근거 없는 강도 점수와 면적 비교는 제거했습니다. 오각형은 사례별 다섯 관찰 항목을 읽는 도식이며, 구체적인 설명 표와 ‘무엇에 주목할지’라는 질문을 함께 제공합니다.

저는 이 프로젝트의 차별점을 지도나 비교 기능 자체의 존재보다 정보가 이해되는 방식에서 만들고 싶습니다. 서로 다른 분류 기준을 구분하고, 같은 단어의 역할과 겹치는 특징을 드러내며, 전체에서 세부로 정보의 깊이를 점진적으로 늘립니다. 사용자는 향수의 이름이나 브랜드보다 향의 방향, 대상, 질감과 관계에 먼저 주목합니다. 탐색 후에는 낯선 단어의 뜻만 아는 것이 아니라, 향수 설명을 읽거나 시향할 때 어떤 차이를 관찰하면 좋을지 더 구체적으로 말할 수 있기를 바랍니다.

1. Concept / Premise

향의 큰 방향에서 구체적인 노트와 감각 표현으로 연결을 따라가며, 향의 구조를 이해하는 인터랙티브 아틀라스.

핵심 대상: 용어가 익숙하지 않거나, 정의를 알아도 관계와 차이가 막연한 사용자.

중심 경험: 전체 8계열 → 계열 선택 → 노트와 특징의 펼침 → 상세 설명 → 필요한 심화 비교.

핵심 메시지: “어떤 향인가”와 “어떤 느낌인가”는 서로 다른 질문이며, 연결을 통해 함께 읽을 수 있다.

이번 선택: A 대안. 원래 지도 안에서 펼치고, 나머지 계열은 현재 위치를 알려주는 맥락으로 유지한다.

범위: 향의 분류·성격·관계·구성. 시간에 따른 향 변화는 포함하지 않는다.

4. Mood / Vision Board

키워드: Quiet / Tactile / Connected / Curious.

기존 화면의 조용한 편집 디자인과 관찰 노트의 분위기를 유지합니다. 꽃잎의 얇은 결, 고운 입자, 마른 목재, 매끈한 표면, 직물 같은 소재는 감각을 생각해 볼 단서입니다. 화려한 제품 사진보다 관계와 의미가 읽히는 공간에 초점을 맞춥니다.

이미지는 실제 향료의 증거 사진이나 냄새 측정 자료가 아닌 시각적 비유입니다. 지도·비교의 캡처는 수정된 웹사이트의 실제 화면입니다.

8. User Flow

대표 흐름: 소개와 유형 차이 읽기 → 전체 8계열 살펴보기 → Floral 선택 → 같은 지도에서 Musk 발견 → Musk의 여러 특징 읽기 → 상세 패널 안에서 두 맥락 비교 → 닫고 같은 위치로 돌아오기 → 공유 계열로 이동.

다른 대표 흐름: Woody 선택 → Cedarwood와 Sandalwood의 노트 의미 읽기 → Dry와 Creamy라는 표현으로 이동 → Woody 안에서 두 질감 비교 → 전체 지도 보기.

탐색은 자유롭습니다. 다른 계열은 항상 남아 있고, 전체 관계 보기로 펼침을 해제할 수 있습니다. 비교를 닫을 때 지도 상태와 호출 버튼의 초점을 유지합니다.

9. Wireframes

주요 화면과 상태:

1. 전체 보기: 8개 계열만 강조된 지도와 시작 안내 패널.

2. 선택한 계열: 선택 계열 주변에 노트·표현이 펼쳐지고 다른 7계열은 보조로 유지.

3. 노트 상세: 관련 특징과 공유 계열을 보여주고, 실제 향료는 필요할 때 공개.

4. 개념 내부 비교: 기존 두 인상 카드와 오각형의 분위기를 유지하는 심화 화면.

5. 모바일: 전체 계열 블록 → 펼친 개념 블록 → 상세 설명의 순서로 재구성.

슬라이드와 assets의 와이어프레임은 위의 상태를 설계합니다. 실제 캡처와 배치도는 구분해서 표시합니다.

비교의 기준

현재 심화 비교는 Soapy / Powdery, Dry woody / Creamy woody, Clean musk / Warm musk의 세 교육용 사례입니다. 사례마다 적합한 다섯 관찰 항목을 정하고, 두 대상을 같은 항목으로 읽습니다. 모든 향에 같은 수치 축을 적용하지 않습니다. 점수와 면적의 근거가 없으므로 특징과 장면의 정성적 설명을 제공합니다.

발표에서 강조할 것

‘예쁜 향 지도’를 넘어, 서로 다른 정보를 구분하고 쉽게 읽는 구조로 재조직한 과정입니다. Type과 Facets를 분리한 이유, 기준 체계를 하나 선택한 이유, 전문 내용을 단계적으로 공개한 이유, 비교를 개념 내부로 옮긴 이유를 설명합니다.
