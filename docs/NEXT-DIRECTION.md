# 현재 선택한 방향 — The Scent Atlas / A 대안

8개 계열의 원래 지도 안에서 선택한 계열 주변에 관련 노트와 감각 표현이 펼쳐집니다.
다른 7개 계열과 전체 맥락은 유지하고, 상세 패널과 개념 내부의 비교로 깊이를 늘립니다.

현재 기획과 구현은 [수정된 제출 자료](../submission-atlas/PROJECT-PROPOSAL.md)에 정리했습니다.
Family 기준은 제공된 리서치의 The Perfume Society 8계열입니다.
Family·Note·Descriptor·Accord·Material의 내부 유형과 사용자 화면을 분리하고,
Type과 Facets를 다대다 관계로 읽습니다. 시간 변화는 제외합니다.

이전 Anatomy의 세 관점 구성안은 `submission/`에 기록으로 보관합니다.
현재 방향은 하나의 향 구성을 분해하는 화면보다 전체 8계열의 관계 아틀라스가 중심입니다.
