# Week 05 — Field notes

## 구현에서 확인한 판단

- 전문 용어는 서로 다른 정보 유형이다. Woody와 Rose를 같은 표시로 놓지 않고
  Family / Note / Descriptor 기호와 설명을 함께 제공했다.
- 연결선만으로는 의미가 충분하지 않다. 모든 관계에 계열–노트, 질감 차이 등의
  이유를 문장으로 연결했다. 직접 연결되지 않은 개념까지 자동으로 강조하지 않는다.
- 공간 지도를 모바일에서 그대로 줄이면 읽기 어렵다. 760px 이하에서 3열 선택 구조로
  전환하고 관계 설명을 아래로 이동했다. 비교의 오각형은 A/B 카드 아래로 옮겼다.
- hover는 탐색 가능성을 알려주는 보조 반응이다. 모든 핵심 정보는 클릭·터치·키보드로
  접근할 수 있으며, hover에만 숨겨진 필수 정보는 없다.
- 선택 전환은 배경·테두리·opacity로 관심의 범위를 보여준다. 움직임 감소 설정에서는
  전환과 부드러운 스크롤을 없애도 동일한 정보를 제공한다.
- 폰트는 로컬 패키지로 제공해 앱이 외부 폰트 서비스에 의존하지 않게 했다.

## 실제 검증 — 2026-10-13

`npm run build` 성공. Chromium 기반 `npm test` **11개 통과**.

검증한 동작:

- 12개 개념 모두 설명과 유효한 비교 링크를 가진다.
- Woody 선택 시 Dry / Creamy가 강조되고 Rose가 물러난다.
- 관계를 따라 Cedarwood로 이동하면 정보 유형이 Note로 바뀐다.
- 질문과 비교 프리셋을 선택하면 대상·오각형·구별 문장이 함께 변경된다.
- 임의의 두 비교 대상을 선택하거나 같은 대상을 두 번 골라도 텍스트와 도형이 일치한다.
- 전체 관계 보기, Enter를 이용한 선택, Escape로 참고 자료 닫기, 초점 복원이 작동한다.
- reduced motion에서 CSS transition이 비활성화된다.
- 320 / 390 / 768 / 1024 / 1440px에서 가로 넘침과 지도 노드 겹침이 없다.
- 런타임 JavaScript 오류가 없다.
- 1440px / 390px 스크린샷으로 전체 화면을 확인했다.
- 다시 불러올 때 외부 런타임 네트워크 요청이 없음을 확인했다.

테스트는 기능과 레이아웃의 검증이다. 향 콘텐츠의 전문가 검토나 실제 사용자 학습 효과
검증을 대신하지 않는다. 향 설명과 정성적 예시 값은 편집 초안이다.

## 새로운 피드백을 반영한 다음 질문

첨부한 추가 대화에서는 용어 지도 자체보다 **같은 향을 Notes / Feel / Family로 읽는 경험**이
더 중요하다는 방향이 도출됐다. 기존 v1은 관계 탐색 실험으로 유지하고,
[다음 방향 제안](NEXT-DIRECTION.md)에서 하나의 사례를 여러 관점으로 읽는 흐름을 설계했다.
오각형을 실측 데이터로 오해할 여지가 있는지, 관점 전환이 이해의 변화로 이어지는지
사용자에게 확인할 필요가 있다. 새로운 방향의 관점 전환과 사례 비교는 이후 별도 제출용 디자인 프로토타입으로 추가했으며, 기존 v1과의 통합은 후속 개발이다.
